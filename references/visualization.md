# 视觉选择与交互

本页只负责数值如何映射为视觉与交互。完整的候选淘汰、平台能力匹配和选型记录见 [数据到效果](selection.md)；具体 SDK 类与限制见 [地图能力索引](capabilities/index.md)。

数据、目标与组件的对应关系统一维护在 [选型映射表](selection.md#2-分析目标--字段--聚合--组件)，包括必需字段、聚合方式、实现入口和不适用条件。以下只补充视觉编码约束。

从单位、时间粒度、空间粒度判断；ID、年份、邮编、行政编码、经纬度不是默认强度。求和、平均、计数、加权比率写清口径。极端值可以用 sqrt/log/分位数，但展示刻度、裁剪数量和原始值。

## 参考效果

可采用与图商无关的视觉表达：数量气泡按指标映射面积、先绘大圆、支持点击详情；需要强调的事件可采用稳定核心与呼吸光晕，并提供暂停。底图明暗、配色、分级阈值和时间控制按本次数据与用户目标确定，不固定套用某个厂商 Demo 的样式、业务阈值或本机服务。优先用本次所选地图引擎或图商的原生图层及官方扩展实现，能力不足时采用明确标注来源的补充渲染。视觉参考不改变图商选择；未指定图商且无已授权配置时仍使用 MapLibre + OpenFreeMap。

## 共用与增强

各平台共用 features + visualSpec + filters 业务契约。渲染优先使用各家公开原生覆盖物/图层或官方扩展；确认能力缺口后可复用适合目标地图的补充渲染器。颜色与大小域从全数据固定计算，切换平台和筛选时不重算。原生路线由 SDK 投影绘制；补充路线核验坐标、容器像素与 DPR，并跟随相机/resize 更新。动画可更新 SDK 属性或补充层状态，按实际归属记录。MultiPoint 展开但保留母 ID，线面不随意变为质心点。

增强先查原生层或官方扩展；不足时可用第三方渲染、自定义 shader 或 Canvas，并核实与目标地图/版本的兼容性，标明能力差异。Google 旧 HeatmapLayer 在 2026-05 后的新版本已退出，不能照搬旧示例；详见 [Google 能力](capabilities/google.md)。

## 性能与交互

根据文件大小、几何复杂度、目标设备与交互需要选择渲染方式；超出当前实现的性能边界时使用聚合/WebGL/服务端切片，不静默抽样。大量数据先汇总，保留源记录数和汇总后记录数。不存在跨设备通用点数上限，正式页面测量交互响应和帧率。

详情使用 textContent，不把上传内容当 HTML。图例标单位和阈值，筛选支持全部与空结果。支持 reduced-motion、键盘操作和动画暂停；暂停后地图仍可交互。保留地图版权、logo 和归属文本，面板避免遮挡。

## 成品视觉检查

- 数据有洲、国家、类型等类别时，先判断类别是否有助于用户比较。少量类别可用固定离散配色并显示图例；类别过多时采用较高层级分组或筛选，不给几十个国家强行分配难以区分的颜色。分类颜色不使用暗示大小顺序的连续色阶，缺失类别有明确中性色。
- OD / 飞线：起点、终点、连线和动画分别承担位置、连接与方向含义。目的地分组时，连线、移动粒子、固定终点和图例使用同一色表；起点突出但不掩盖终点。暂停动画后仍能看清全部连接与端点。点击端点可查看名称、国家/地区及已有指标；没有流量字段不编造线宽差异。
- 全局图与局部图都检查：密集线降低透明度并允许分类筛选；点重叠可缩放、聚合或调整描边；气泡先绘大值，避免掩盖小值。颜色、尺度与筛选统计保持一致。
- 热力不能大面积饱和成一块：结合当前数据密度调整半径与强度，在固定时段间保持同一尺度。3D 需从默认视角看出高度差，但比例与单位必须说明。雷达图使用有意义的共同尺度，标签可读，不能把分类数量称为质量评分。
- 浏览器验收至少检查默认全景、一个局部缩放、一次拾取/筛选与动画暂停。不能仅凭“图层已加载”判定视觉效果合格；记录遮挡、颜色辨识度、端点可见性、图例可理解性与真实截图结果。
