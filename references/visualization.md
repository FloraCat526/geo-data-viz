# 视觉选择与交互

本页只负责数值如何映射为视觉与交互。完整的候选淘汰、平台能力匹配和选型记录见 [数据到效果](selection.md)；具体 SDK 类与限制见 [六家能力索引](capabilities/index.md)。

| 数据条件 | 推荐效果 | 避免误表达 |
|---|---|---|
| 点、非负数量/规模 | 气泡图，半径按 sqrt(value/max)，面积表达数值 | 半径线性会夸大数量；最小可见半径需说明 |
| 点、事件强弱/等级 | 呼吸点、波纹；固定分级颜色、稳定核心点 | 装饰动画不暗示数据实时变化 |
| 密集点、关心分布 | 聚合、网格计数或热力 | 密度不代表风险或比例；缺失不当零 |
| 正负变化值 | 发散色阶，大小映射绝对值并说明 | 不对负数开根号、不截断负值 |
| OD 对、流量 | 宽度/颜色表达流量，弧线表达方向 | OD 示意连线不是实际道路 |
| 有序轨迹 + 实体 ID + 时间 | 时间轴、轨迹回放、尾迹 | 不连接不同实体，不编造缺失轨迹 |
| 多边形 + 数值 | 分级设色、边界高亮 | 比例汇总不能直接平均，零和缺失不同 |

从单位、时间粒度、空间粒度判断；ID、年份、邮编、行政编码、经纬度不是默认强度。求和、平均、计数、加权比率写清口径。极端值可以用 sqrt/log/分位数，但展示刻度、裁剪数量和原始值。

## 参考效果

参考视觉方向为 Maptec BubbleChart 和 BreathingPoints：气泡图暗底、先绘大圆、黄橙红色、大小控制、点击详情；呼吸点绿/黄/红分级、稳定核心与光晕、时段切换及暂停。这些是视觉方向，不是业务阈值；不将新加坡交通阈值套用到上传数据，不依赖本机 Demo 服务。自行实现同类视觉语言，不复制无关数据。

## 共用与增强

各平台共用 features + visualSpec + filters 业务契约。渲染可用公开原生覆盖物或共同视觉层，按任务选择。颜色与大小域从全数据固定计算，切换平台和筛选时不重算。投影缓存随地图变化刷新，动画只修改视觉参数。MultiPoint 展开但保留母 ID，线面不随意变为质心点。

增强按平台能力文档选择原生层、官方扩展或第三方层，先核实版本文档。Google 旧 HeatmapLayer 在 2026-05 后的新版本已退出，不能照搬旧示例；详见 [Google 能力](capabilities/google.md)。

## 性能与交互

根据文件大小、几何复杂度、目标设备与交互需要选择渲染方式；超出当前实现的性能边界时使用聚合/WebGL/服务端切片，不静默抽样。大量数据先汇总，保留源记录数和汇总后记录数。不存在跨设备通用点数上限，正式页面测量交互响应和帧率。

详情使用 textContent，不把上传内容当 HTML。图例标单位和阈值，筛选支持全部与空结果。支持 reduced-motion、键盘操作和动画暂停；暂停后地图仍可交互。保留地图版权、logo 和归属文本，面板避免遮挡。
