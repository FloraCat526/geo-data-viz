# 按需转换地理数据

profiler 只分析已有几何或一对经纬度字段，不自动完成以下语义转换。Agent 根据输入和用户问题选用所需步骤，在工作目录保留转换脚本和关联报告，再对结果运行 profiler。确定的信息直接使用；缺少会改变结论的关键项才询问。

## OD（起终点关系）

- 绑定 origin_lng/lat、destination_lng/lat、关系 ID、方向与可选流量，分别核对来源 CRS。
- 校验两端，保留无法定位的行与原因；一行多目的地时明确展开后的记录粒度，不能重复汇总总流量。
- 输出 LineString 的两端连接作为 OD 关系，或有明确方法的曲线。显示“起终点关系线”，不称驾车路线，不从两点伪造中间采样或实际速度。
- 驾车路径是另外的路线服务调用；只有用户任务需要且接入具备时请求并保存返回来源。

## 轨迹

- 明确实体 ID、采样时间/时区与位置。按 entity ID 分组，再按解析后的时间排序；不能把不同实体连在一起。
- 同时刻冲突、不可解析时间、缺位置保留记录与处理理由。时间缺口阈值依据采样频率/业务说明，不写一个通用固定分钟数。
- 缺口处断开。只有一个点的片段保留为点，不能补造第二点；路径与回放时间数组长度一致。
- 保留每个片段的 source IDs、起止时间与可解释的分段原因。均匀动画插值只能标为展示插值，不代表实际观测位置。

## 区域边界关联

- 用户已有边界时优先使用。只有地名/行政编码时，查明区域与边界年份，从有来源的边界数据关联，不能画猜测多边形。
- 编码按字符串读，保留前导零。验证 join key 唯一性，记录未匹配统计、无统计的边界、重复关联；不要因名称重复形成笛卡尔积。
- 比率上卷为 sum(numerator)/sum(denominator)，分母为零/缺失单独处理。只有已有比率时可直接显示，不能假装知道跨区汇总率。
- 输出真实 Polygon/MultiPolygon，保留内环；区域标识、单位、统计时间与边界时间随数据保存。

## 混合几何与 MultiPoint

先递归枚举几何子项，保留父 Feature ID 和确定性的子项索引。点/线/面分层表达；子 ID 可由 parent ID + 路径组成。

一条 MultiPoint 记录可能代表一个实体的多个位置，不能把父级销售额在每个子点重复计入热力或聚合总额。只有明确每点就是独立观测时才作为点计数；否则使用实体级统计或请用户确认分配规则。不修改输入源文件。

## Excel 与多表

先列出工作表名称及少量表头，必要时使用 openpyxl 的只读模式；不要因为活动表是默认项就把封面/说明页当数据。单个明确数据表使用 --sheet，关联多表时明确记录粒度和连接键。公式使用缓存值，缓存缺失不当作零。

## 转换验收

对照输入行数、有效实体/关系数、输出几何数、剔除数与原因；几何数变化应能解释。计算指标前确认是否有展开导致重复。只把必要摘要带入模型上下文，原始数据和可复现转换脚本留在工作目录。
