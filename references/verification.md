# 验证边界

本文件描述能力边界，不把历史测试次数当作当前作品的验收结果。

- MapLibre + OpenFreeMap 是默认免 Key 路线；常见点线面组件由 MapLibre 原生渲染。曾在 Codex 浏览器验证底图、常见点线面、深浅主题和部分组件，但不同数据规模、设备与网络仍需本次实测。
- Mapbox 有历史真实 Token 验收记录；其余商业图商的文档、实现与真实 Key 验收范围不同，逐项看对应能力文档。文档存在、SDK 加载或模拟测试通过不等于目标环境已可用。
- 飞线与显式启用的散点加法叠加使用 deck.gl 补充；散点普通模式和柔光仍为原生圆层；蜂窝与呼吸点使用 MapLibre 原生图层。输入范围和效果限制见 maplibre-effects.md。
- 自动化测试验证数据处理、生成和模拟图层行为；不能证明 AI 对任意业务的选型都正确。Claude Code、WorkBuddy 等宿主的完整会话需要分别评估。
- npm 已发布包与仓库未发布源码可能不同。使用当前安装目录中的实际文件，不把最新 README 当作旧包的能力说明。
- 矢量、影像和地形配置需分别验收底图来源、真实瓦片与 DEM；OpenFreeMap 默认矢量路线的历史验收不能证明其他影像/高程服务已通过。地形上原生层、deck.gl 补充层的贴地与遮挡需按所用组件检查。
- `SceneNarrativeViz` 的场景采样与 HTML/视频生成可以做本地代码验证；MapTiler、Cesium ion、3D Tiles 的真实 Key 和资源加载另行验证。未提供授权资源时不标为真实山地/三维城市已验收。
- Remotion 工程生成、预览帧渲染与完整 MP4 输出是不同验收项。记录实际执行的项、画面和音画同步；高德、百度、腾讯、Google 的专用 Remotion 导出不在当前已封装范围内。

每次交付分别记录数据与统计校验、代码检查、真实浏览器画面及未验证项。缺 Key 或浏览器时标注待验收。历史验收报告与内部测试、评估材料仅作本地开发记录，不随源码或 Skill 分发。
