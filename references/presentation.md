# 生成作品的布局与交互

本页适用于 MapLibre/Mapbox 的通用 HTML 配方；其他图商可复用页面语义，数据层仍使用对应图商能力。用户目标明确时直接选择，不强制用户配置每个选项。

## 配置

```json
{
  "title": "门店订单分布",
  "description": "比较门店订单规模。",
  "dataDescription": "统计周期为 2026 年 9 月；缺失记录不计入合计。",
  "effect": "bubble",
  "unit": "单",
  "aggregation": "sum",
  "layout": "explore",
  "theme": "light",
  "detailFields": [{"field": "address", "label": "地址"}],
  "maxRadius": 28,
  "alternatives": [{"effect": "heatmap", "weight": "count"}]
}
```

- `layout`：explore 默认展开搜索/筛选；presentation 放大标题和指标，默认收起筛选；report 使用紧凑报告样式、筛选默认收起。三者均支持 dark/light，面板与图例可收起，手机采用底部面板。不是三种新渲染器。
- `description`：主效果说明；备选只有显式提供自己的 description 才使用，否则显示共享的 `dataDescription`。每个效果另有与渲染对应的自动编码解释。不要把“气泡面积”之类解释放进共享 dataDescription。
- `aggregation`：默认 none，只显示记录数与缺失情况。可选 sum 或 mean，由 AI 确认统计口径后设置；不对温度默认求和，不对区域比率做无分母的平均。当前 mean 是有效值的非加权算术平均，不是加权比例。空结果/全缺失显示未提供，不伪造为零。
- `detailFields`：显式选择源 properties 的标量字段及显示标签；不支持嵌套对象或未知字段，不默认复制整行。上传字符串经文本节点展示。
- `maxRadius` / `heatRadius` / `lineWidth`：正数，最大 100 像素，默认 28/22/3；每个备选单独配置。改变最大半径仍保留面积比例，不是最小半径裁剪；固定线宽不表示流量。复杂的缩放插值、按流量宽度和多图层仍需 Agent 按原生 SDK 扩展。

## 不变的语义

- 记录数、缺失数和已选择的合计/均值随当前筛选更新，始终注明当前/全部。图例的颜色域和大小域固定为全数据。
- 气泡提供真实尺寸样本；小于 2 px 的非零气泡仍保留原半径，叠加原生 symbol 十字位置标记，不把标记面积当成指标。优先绘制大圆再绘小圆；参见 [MapLibre circle-sort-key](https://maplibre.org/maplibre-style-spec/layers/#circle-sort-key)。点选择使用原生 circle 高亮。
- profile 的 `visualHints.bubble` 报告按最大半径 28 px 估计的小于 2 px 点数，用于发现长尾问题，不是自动决定主图的规则。可改用指标颜色、聚合或明确的其他表达，不能静默删除极端值。
- 连续色阶的渐变按实际数值域定位色标；热力颜色表示相对密度，不是可读数的连续指标；图例不把两者混用。
- 搜索按名称，和类别、起止日期联合过滤。日期按规范化时间字符串中的日历日期比较，未提供时间的记录在启用日期范围时排除；如果任务需要跨时区瞬间比较，先统一时间语义再生成。日期范围倒置产生空结果，用户可清空条件。
- 名称列表按 20 条分页加载，可用键盘打开详情；不减少地图中的记录数。选中点高亮、实体详情和筛选在深浅主题切换时保持，效果切换清除旧选择。没有时间范围时不显示无用日期控件。

## 交付检查

检查全量→类别+搜索→时间→空结果→清空；切换效果后说明与编码匹配。检查极差大的气泡和同点多实体是否能访问，详情字段是否仅包含显式允许内容。检查深浅主题、三种布局、窄屏收起/展开、图例、来源与版权。真实浏览器无法执行时标记待验收。

当前原生打包器处理一组兼容几何与一个主指标；点+区域边界等多层组合、轨迹回放和加权比率必须另行设计与验证。数据规模应按文件字节、顶点数、目标设备和实测响应选择策略；现有全量内嵌路径不声明大数据服务能力。

## 信息层级

默认首屏保留标题、可选一行 `subtitle`（统计期、空间粒度等）、关键统计和操作。图商/SDK 名称留在技术验收信息中，不重复占据业务面板；地图版权署名仍按服务要求保留。页面不提供“数据说明”入口；`description` 和 `sourceLabel` 保留在产物元数据及随附说明中，不在业务面板显示。必要来源和许可仍随产物保留，地图服务要求的可见署名不得移除。影响判断的单位、颜色尺度、3D 指标高度含义仍留在图例。

未选择对象时不显示空详情，筛选为空时隐藏清空按钮；无缺失不显示“缺失 0 条”提示。缺失影响统计时显示提示，过滤结果仍注明全量数量。避免标题、图例和面板重复解释同一内容。

可选 `recordLabel` 和 `metricLabel` 给统计卡使用明确的业务名称，例如“住宅网格”和“住宅”（单位仍单独显示）；未配置时保留通用名称。面板优先用字号和留白区分层级，避免每个字段都套厚重卡片；标题简短，统计期和粒度放在一行 subtitle。

`showRecords: false` 可移除记录列表，仍保留地图点击详情；密集网格与路线示例采用此设置。默认隐藏记录列表；只有用户需要逐条浏览时显式设置 `showRecords: true`。

## 语言与配置检查

`locale: zh-CN | en` 控制模板文案、页面语言与数字格式，默认中文；Agent 根据用户语言显式选择。标题、单位、类别和详情原文不自动翻译，应由 Agent 按任务提供。未知配置字段（包括备选效果与 colorScale）会报 UNKNOWN_SPEC_FIELD 并尽可能提供拼写建议。

临时资源错误在数据层已注册且瓦片恢复后清除；鉴权与数据配置错误保留提示。重试按钮重新加载页面，会重置当前交互状态；缺少 Token 需重新生成授权配置。

热力图图例与原生图层共用密度颜色节点，区分地点计数密度与指标加权密度；两者均为相对密度，不用于直接读取精确数值。分级区间以 x 表示当前指标，避免英文界面混入中文标签。聚合点展开遵循系统减少动画设置。
